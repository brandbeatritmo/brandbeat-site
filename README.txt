BRANDBEAT — SITE COM IDENTIDADE VISUAL DA MARCA
================================================
Arquivos incluídos:
- index.html — estrutura do site
- style.css — cores, layout, fontes e responsividade
- script.js — menu mobile e interações simples
- brandbeat-logo.png — logo original com assinatura
- brandbeat-simbolo.png — símbolo original para o destaque visual e favicon

IDENTIDADE APLICADA:
- Gradiente da marca: laranja → rosa/vermelho → magenta → roxo
- Azul-marinho profundo para contraste e áreas escuras
- Fundos claros com nuance rosada
- Outfit nos títulos e DM Sans nos textos; o logo oficial mantém o lettering original da marca.

PUBLICAÇÃO GRATUITA NO GITHUB PAGES:
1. Crie um repositório público chamado brandbeat-site.
2. Envie TODOS os arquivos deste pacote para a raiz do repositório.
3. Acesse Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Selecione a branch main e a pasta /root; salve.
6. O GitHub exibirá o endereço público do site.
